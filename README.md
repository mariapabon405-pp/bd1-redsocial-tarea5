## Descripción del Proyecto

Implementación del sistema de consultas avanzadas (DML), vistas (`VIEW`) y manipulación de datos semiestructurados (`JSONB`) para la plataforma académica **Comunicación Pascualina**. El proyecto abarca desde la creación de las 15 tablas relacionales y la inserción de registros de prueba hasta la resolución de 5 preguntas de negocio mediante operaciones de conjuntos (`UNION`, `EXCEPT`), agrupaciones (`GROUP BY`, `HAVING`) y reuniones (`INNER JOIN`)
